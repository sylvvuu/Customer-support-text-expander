## 1. 앱 이름
- 영문: Swiftree
- 한글: 스윗트리

## 2. 짧은 설명
웹페이지에서 드래그한 문장을 우클릭 한 번으로 모음에 저장하고, 카드를 누르면 바로 복사할 수 있어요.

## 3. 상세 설명 첫 줄
Swiftree(스윗트리)는 고객 응대를 위한 문장 모음집입니다.

상세 설명 본문은 `listing.txt`를 따릅니다.

## 6. 개인정보 보호 탭

**전용 목적 설명**
Swiftree는 사용자가 웹페이지에서 드래그해 고른 문장을 모음별로 저장하고, 저장한 문장을 클릭 한 번으로 복사하도록 돕는 확장 프로그램입니다.

**contextMenus 사용 근거**
사용자가 웹페이지에서 드래그한 문장을 우클릭 메뉴에서 모음에 저장할 수 있도록 사용합니다.

**storage 사용 근거**
사용자가 저장한 문장과 모음 목록을 브라우저에 보관하고 다시 불러오기 위해 사용합니다.

**원격 코드**: 아니요, 원격 코드를 사용하지 않습니다.

**수집하는 사용자 데이터**: 없음. 어떤 항목도 체크하지 않습니다.

**데이터 사용 인증**: 3개 모두 체크
- 판매하거나 제3자에게 전송하지 않습니다.
- 신용도 판단이나 대출 목적으로 사용하지 않습니다.
- 목적과 무관한 용도로 사용하지 않습니다.

**개인정보처리방침 URL**: 아직 없음. `privacy-policy.md`를 GitHub Pages로 공개한 뒤 입력합니다.
