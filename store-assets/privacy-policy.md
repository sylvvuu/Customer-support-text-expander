# 내 문장 모음 개인정보처리방침

최종 업데이트: 2026년 11월 19일

## 1. 수집하는 정보
내 문장 모음은 사용자의 개인정보를 수집하지 않습니다. 계정 가입도 없고, 방문 기록이나 웹 활동을 추적하지도 않습니다.

## 2. 저장하는 데이터
사용자가 저장한 문장, 모음 이름과 목록은 이 브라우저의 확장 프로그램 저장소(chrome.storage.local)에만 보관됩니다. 저장 시각과 문장이 나온 페이지 주소도 함께 보관될 수 있으며, 이 역시 기기 밖으로 나가지 않습니다.

## 3. 외부 전송
확장 프로그램은 어떠한 데이터도 외부 서버로 보내지 않습니다. 제3자에게 제공하거나 판매하지 않습니다.

## 4. 데이터 삭제
- 팝업에서 문장을 개별 또는 전체 삭제할 수 있습니다.
- 확장 프로그램을 제거하면 저장된 모든 데이터도 함께 삭제됩니다.

## 5. 사용하는 권한
- contextMenus: 우클릭 메뉴에 모음 저장 항목을 추가하기 위해 사용합니다.
- storage: 저장한 문장과 모음 목록을 기기 안에 보관하기 위해 사용합니다.
