# 내 문장 모음 (Chrome 확장 프로그램)

웹페이지에서 드래그한 문장을 우클릭으로 모음에 저장하고, 팝업에서 복사하는 확장 프로그램입니다. 외부 서버로는 아무것도 보내지 않습니다.

- 개발자: 이은정
- 버전: 1.1.0
- 제작일: 2026-11-19

## 폴더 구성

- `extension/` : 확장 프로그램 소스 (manifest.json, background.js, popup.html, popup.js)
- 1차 시안 HTML 프로토타입 (흐름 테스트용): https://claude.ai/artifact/WCGfG9UKZd9o9fPcpuy4Dd

## 설치 및 테스트

1. `chrome://extensions` 에서 개발자 모드를 켭니다.
2. "압축해제된 확장 프로그램을 로드합니다"를 누르고 `extension/` 폴더를 선택합니다.
3. 웹페이지에서 문장을 드래그한 뒤 우클릭하고, 메뉴에서 모음을 고르면 저장됩니다.
4. 툴바의 "내 문장 모음" 아이콘을 누르면 팝업이 열립니다.

시크릿 창에서 쓰려면 확장 프로그램 세부정보에서 "시크릿 모드에서 허용"을 켭니다. 이 설정은 실행 여부만 바꾸고, 시크릿 창의 저장 공간은 일반 창과 분리됩니다.

## 주요 기능

- 모음 3개 기본 제공 (배송 안내, 쿠폰 안내, 교환·반품 안내) + 미분류
- 모음 관리: 추가, 이름 변경, 삭제 (최대 8개, 이름 10자 이내, 미분류는 삭제 불가)
- 모음을 삭제하면 안의 문장은 미분류로 이동
- 복사, 개별 삭제, 전체 삭제 (확인 팝업)
- 중복 저장 방지, 300자 제한
- 저장 개수 제한 없음

## 시행착오 정리

1. **디자인 캔버스 시안으로는 흐름 테스트가 어려웠습니다.** 팝업과 웹페이지가 따로 떨어져 있어 저장 흐름을 끝까지 볼 수 없었습니다. 그래서 단독 HTML 프로토타입으로 다시 만들었습니다.
2. **Chrome 우클릭 메뉴는 디자인을 바꿀 수 없습니다.** 자체 메뉴는 페이지에 스크립트를 넣어야 하는데, 과제 권한 범위(contextMenus, storage)에서는 기본 메뉴를 써야 했습니다.
3. **설치 직후 중복 ID 오류가 났습니다.** `root` 메뉴를 만드는 작업이 두 번 겹쳐 실행되면서 `Cannot create item with duplicate id root` 오류가 났습니다. 메뉴 생성을 한 번에 하나씩 실행하도록 고쳐서 해결했습니다. (1.0.0 → 1.1.0)
4. **시크릿 창에서 저장 내용이 안 보였습니다.** 기본값은 시크릿 창에서 확장 프로그램이 꺼져 있고, 허용을 켜도 저장 공간은 분리됩니다.
5. **과제 조건과 어긋나는 변경이 있었습니다.** 저장 30개 제한을 없애서, 과제 요구사항과 비교해 확인이 필요합니다.
